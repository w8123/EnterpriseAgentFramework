# ReachAI 管理端 UX 契约

## 产品上下文

- 受众：企业 Java 系统研发、AI 平台管理员、Workflow/Agent 构建者与运行治理人员。
- 核心任务：接入业务系统与能力、评审能力变化、编排 Workflow、配置 Agent、查看运行证据并治理权限。
- 产品语言：简体中文；框架与协议正式名保留 `Agent`、`Workflow`、`MCP`、`A2A` 等英文身份。
- 无障碍目标：WCAG 2.2 AA；键盘、焦点、非颜色状态提示和 200% 缩放为基础验收项。

## 交互与表单

- 全站间距遵循 `DESIGN.md` 的紧凑工作台尺度与 `_layout.scss`／`_density.scss`；列表筛选、表体和分页共用面板内缘，局部与响应式覆盖不得重新引入重复大内缩。收紧横幅及统计时保留完整状态、主要动作和说明，按内容换行或增高，不用固定高度截断。控件点击尺寸、表格信息层级、现有滚动归属和查询行为保持各自既有契约。

- 看起来可点击的元素必须有真实动作；当前状态、范围和进度使用文本、状态芯片或语义列表，不伪装成按钮。
- 所有应用自有 `<form>` 使用 `novalidate`，错误由产品文案呈现；输入值在失败后保留。
- 文字输入区使用 `resize: none` 并提供足够高度或 autosize；`Ctrl/Cmd + Enter` 在 IME 组合输入期间不得提交。
- 长请求采用悲观提交：提交期间禁用重复动作，失败时保留上下文并提供原位重试。具体领域状态以对应 API 契约和页面 composable 为准。
- 业务方法试调用在 POST 前保存当前账号／项目／方法的调用 ID 与时间，不保存输入或结果。持久查询键不包含会话内的请求代数；刷新或重新打开仅查询原 ID，UNKNOWN／响应丢失提示可能已经执行。写入的新尝试必须新 ID 与新确认，请求失效和权限撤销仍清除敏感状态。
- API Console 按已接纳契约支持 GET／POST／PUT／PATCH／DELETE；对象、嵌套 JSON、根数组和标量复用业务方法输入编辑器的具名 HTTP 模式。根数组和标量使用完整 JSON；text/plain 也以 JSON 字符串编辑，派发编码由服务端按接纳媒体决定。缺省请求体与显式字段 null 保持区分，不代填来源 default；无效 JSON 保留原草稿并禁止派发。multipart、二进制及未支持的声明继续显示服务端阻断理由，不猜测为 JSON。只有已审查的 NONE／READ_ONLY 免写确认；WRITE／IDEMPOTENT_WRITE／IRREVERSIBLE 都必须逐次确认，包括没有请求体的写操作和带副作用的 GET，未知性质禁止新调用。明确确认绑定目标、契约、来源、连接／凭据修订及完整输入；变化或刷新即失效，初始焦点落在取消。写操作不重试、不跟随重定向，HTTP 错误和 UNKNOWN 均不表示业务未执行。复用共享查询句柄，仅按稳定账号／项目／环境／API 保存 ID 和时间，重开与整页刷新只查询；显式新调用先警告上次可能生效，再准备新 ID 并重新确认。Studio 不开放写 API 的草稿真实试运行；已发布 Workflow 的受控 POST 按既有固定 pin、可信入口、风险／授权与确认机制执行，不借用 Console 的确认凭据。调用／查询错误使用原位安全反馈，平台 401 仍由共享层处理。
- API JSON body 区分可选字段缺省与显式 null：缺省省略，不可空字段的显式 null 在确认弹窗和派发前拒绝；false、0、允许的空串保持原值，不代填来源 default。敏感适配依据已接纳契约的 format: password／writeOnly: true 及既有名字规则，表单和 JSON 默认遮蔽；结果用本次已验证契约固定的内存敏感值集合脱敏，不信任客户端标记。此规则不改变 GET 或 Java 业务方法的 null 语义。
- HTTP API 连接保留 owning service 的具体受阻原因；`configurationAllowed=true` 时允许修正旧地址或失效凭据，并按当前修订保存，试调用仍要求 `CONFIGURED`。来源未确认、契约未接纳或 multipart / 未知媒体等不支持形态由服务端返回 false，点击和键盘均不能保存；旧响应缺少该字段时，BLOCKED / 未知状态保持禁用。JSON 对象和数组响应使用真实媒体证据，不凭接纳结果推断可调用；媒体缺失时核对业务转换器或显式声明后重新同步并接纳。
- API Console 的 RunOps 结论保留 UNKNOWN 未确认语义；当所属 Console 根阶段只有通用错误时，可补充 owning Runtime 提供的严格白名单传输原因、异常类与有限耗时。只接受完整格式及一致的 code/异常类组合，显示固定中文说明，不能优先输出任意原始错误、URL、参数或凭据，也不据 TLS 失败猜证书不可信。试调用次数、执行阶段和实际 Tool 审计分别显示；空审计说明没有记录，不能推断未派发，无对应审计记录的节点不提供工具调用跳转。
- Studio 发布请求显式使用 `errorFeedback: 'local'`，错误提示由发布领域 composable 负责，避免共享请求层先弹裸码或重复反馈；平台 401 的分类、会话清理与登录跳转仍由共享请求层处理，原错误继续返回。版本页等未选择本地反馈的请求保留全局默认行为。
- Workflow 发布遵循 [`发布生命周期契约`](../docs/architecture/workflow-semantic-contract.md)：Studio 与版本页均传已读取修订，发布人由登录身份记录。版本页发生冲突时保留版本号/说明，提供刷新状态后重新检查的入口。回滚确认明确说明切换活动版本并保留编辑草稿；当前只提供全量发布。
- Workflow 普通编辑与 Studio 保存必须携带已读取的草稿修订，缺失时保留输入并提示重新加载，不自动覆盖。SDK、SYSTEM 和 AI_QUICK_ACCESS 定义只读展示；定义来源、创建入口和生命周期状态由 Workflow 维护。USER／AI_CODING 草稿可继续在 Studio 编辑，保持原创建入口。
- Workflow 调试依据 [会话提交与恢复契约](../docs/architecture/runtime-audit-attribution.md#调试会话的提交与恢复)：接纳后立即沿用现有存储保存会话标识。断流不自动重发执行；“重试”和重新打开面板查询原会话。进行中记录显示结果尚未确认，临时查询失败保留标识和上下文。Tooltip 不得拦截其内实际操作按钮的 Enter／Space。
- 调试会话到期时显示服务端保存的结果无法确认说明，引导核对运行记录和业务系统；“重试”仍只查询。恢复终态不能重新开放历史交互，错误提示中的操作按钮不能被长文案挤成竖排。
- 创建调试请求发出前保存当前账号／Workflow 的一次尝试标识，不保存输入内容；首个响应丢失时按此标识只读查询。尚未查到接纳记录不能据此认定未执行或自动重新创建。取得会话后转换为会话 ID 引用，显式新调试使用新尝试标识。
- 调试会话引用按已登录账号和 Workflow 分开保存，旧无账号引用不能恢复。退出登录或切换账号时立即清空调试输入、结果和传输实例；旧请求的迟到响应不能出现在新账号界面、清除另一账号引用或将旧输入重新发出。同账号切走再切回也必须丢弃此前响应，服务端所有者授权始终是最终边界。

## 导航与响应式

- Java 目录仅在侧栏已确认“全部项目”时显示项目筛选，默认“全部项目”，选项来自当前账号可读项目。目录项目保存为独立 `methodProjectId`，不把侧栏或全局 `scope/projectId` 切到该项目；侧栏具体项目优先并隐藏目录项目下拉。项目即选即筛，一次 URL 更新同时清当前分类、页码和旧详情定位，保留关键词草稿、已提交关键词、启用状态及 HTTP 查询。分类索引与列表使用同一有效目录项目，切回全部项目禁用分类筛选；失效、不可见或非法项目值阻止读取，选择全部项目可恢复。刷新／浏览器返回恢复本地项目、分类及分页。目录筛项目仅用于浏览，分类调整继续要求侧栏具体项目。

- Studio 校验与冲突恢复遵循 [工作副本异步结果归属](../docs/architecture/workflow-semantic-contract.md#23-studio-工作副本异步结果归属)：切换或重新加载文档后，旧响应及旧确认不得覆盖当前内容；同 ID 往返也须失效。覆盖本地内容的冲突按钮不默认聚焦，取消与 Escape 保留输入，正常显式确认仍可重新加载。

- 主导航按用户资产路径排序：业务能力 → Workflow → Agent。按 2026-10-10 用户确认的 D13，业务能力外层只提供“能力目录／接入与变更”；Java 业务方法／HTTP API 的 Element Plus 分类 TAB 仅在目录显示。页头操作区只放工作视图导航，目录“整理”菜单位于类型 TAB 行右侧；分组管理、批量整理说明、关联分析从该菜单打开，保留稳定深链和返回目录；不恢复五个平级入口。两类资产继续各自维护契约、连接与调用条件。页头沿用紧凑 plain 变体，不显示装饰图、重复项目标题或范围说明卡。
- 两个 TAB 使用可直接访问的嵌套路由，刷新、浏览器返回和详情返回恢复已提交的筛选/分页；URL 字段分别使用 method/api 前缀，搜索与重置只改变当前 TAB。只挂载当前面板，切换或卸载后丢弃旧请求；跨项目、账号或未确认范围不得显示旧资产或试调用结果。列表总数使用 owner 返回的完整查询总数，失败时显示读取失败，不通过当前页记录猜总数，也不把“已启用”称为“可用”。
- HTTP API 详情路由只匹配正整数资产 ID，不能把 sources/groups/semantics/graph 解释为详情身份；项目共享视图保留 URL 中的类别上下文，回到资产目录时恢复原类别和两类已提交的筛选，生产路由表与详情路径一起做导航回归。
- API 市场功能位置使用白名单 `marketTab` 查询参数。API 详情返回“我的接入”时保留已确认项目、原查询和 hash；接入列表复用共享项目范围，不将不可访问的 URL 项目猜成侧栏项目。公开发现目录在未选项目或没有项目授权时仍可查看，受控接入与创建动作按当前项目权限读取。
- 两个目录共用 `BusinessCapabilityCatalogList.vue`，复用 `DataTableShell` 和 `FilterBar` 的紧凑密度；两类目录均使用业务分类下拉及各自的领域筛选；Java 在侧栏全部项目时于关键词与业务分类之间增加项目下拉。两类目录从搜索栏直接进入列表，不显示顶部统计或查询概览；Java 不发起专用 summary 请求，HTTP 也不为已退场的“匹配 API／环境范围／HTTP 方法”概览建立独立读取。列表底部总条数继续使用正式 owner 分页结果。筛选条与表格复用项目列表的玻璃、表头、边框、焦点和页脚 recipe，输入／下拉／按钮统一 40px。桌面目录填充既有内容区并与侧栏底部对齐；表体局部滚动，960px 及以下恢复自然高度，共享来源等表单视图保持自然流。筛选操作区仅保留“搜索”，不提供清空全部筛选或手动刷新目录按钮，空结果区同类清空入口一并移除。条件可通过各字段自身的清空入口逐项调整；首次加载、范围切换、筛选分页、分类保存后的数据更新及失败重试沿用原路径。单页与多页都显示总条数、上一页/页码/下一页和每页条数；单页翻页禁用，页大小变更与翻页沿用原查询事件。方法名称和“查看”均打开同一详情；侧栏具体项目不重复行内项目名、保留来源元信息；全域隐藏整条所属项目／来源元信息。HTTP API 保留环境、HTTP 方法、来源状态筛选，退场范围只包括顶部概览及其专用派生状态。
- 资产目录的分类切换保留工作台和侧栏实例及 TAB 键盘焦点；工作视图切换保留页头和外层导航实例、项目范围与 URL 查询。首次项目范围确认保留书签页码，后续真正切换已确认项目/账号才重置方法分页。目录查询写回绑定挂载时的路由；离开导航开始即停止旧分页/筛选写回，导航被拒绝后恢复，不能取消来源等目标视图的异步导航。390px 窄屏复用侧栏折叠入口与目录局部表格滚动，主要筛选及查看操作必须可达。
- 目录分类与下拉条件即选即筛，关键词通过 Enter／搜索提交；只提交当前操作指定的字段，保留未提交文本，不借分类/下拉切换偷偷提交或清除关键词。URL 的已提交字段变化恢复对应字段，项目/账号变化仍沿用上下文清理保护。Java 业务方法与 HTTP API 列表始终平铺，不保存分类折叠状态；两类分类下拉使用 Element Plus 的选中态和键盘语义，选择或清空分类回到第一页。

- 接入与变更的项目接入信息、来源集合和业务说明独立呈现；变化评审在项目身份确认后即可读取，不等待来源或说明。来源的分组名称由既有来源响应携带，不再另取全部分组；模型选项只在打开批量说明或首次生成时读取。说明未返回或失败时明确显示读取状态，不能标为未补充；来源读取失败保留变化区域与刷新入口，禁止将缺失集合显示为空或导出。首次挂载由变化组件读取一轮，手动刷新同时重读既有变化与来源；说明和关联分析各自只读取所需数据，切换视图停止旧任务轮询并忽略旧响应。

## 权限与反馈

- 业务能力目录在一次筛选或翻页后只发起一次列表查询；目录查询只由其所属路由发起，进入详情或其他工作视图时不得因共享项目范围修订再读旧目录，取消导航后当前目录仍可筛选与切项目。分类归属按当前可见资产批量读取，返回的逐项修订仍用于冲突保护。接入与变更使用服务端来源分页与全局统计，导出时按需读取完整来源；页码、关键词、分类及能力定位沿用路由状态。业务说明索引不包含正文，选中后才读取对应 typed owner 正文；切换主体、项目或卸载后旧正文响应与错误不得覆盖当前阅读器。参数提示来自同次 enrichment 读取，重试面板重读同一主体，不能新增重复提示请求。候选显示开关只读取候选；图谱只绘制当前视口所需卡片和关系，保留选择、键盘、拖动和连线锚点。
- HTTP API 详情默认只读取当前资产及必需连接状态；使用位置在对应 TAB 或接入信息的接纳影响中按需读取，共用一次当前页面读取。项目凭据仅在接入信息打开后读取，不能阻塞连接状态呈现；失败明确未知并提供重读，含凭据的连接保存须等待列表确认，旧项目/账号响应不得恢复。批量归类的分类集合与当前归属并行读取，两者都核实后才允许保存。图谱正式快照到达即结束主加载；候选关系有独立的加载、失败与重读状态，失败不遮蔽正式关系，关闭候选或切项目后迟到结果不得恢复。

- 调用权限的新建、编辑、批量授权和诊断共用明确的项目范围选择；初始未选范围不提交，平台范围须显式选择。编辑保持原有范围，遗漏字段不清除项目限制；批量幂等按完整项目范围区分，诊断传递同一项目身份。项目ID/code、角色或目标变化立即清除旧诊断结果；关闭、重开及卸载使在途请求失效，旧response/error/finally不得覆盖当前结果或结束新查询。来源变化评审的oldValue明确标为“变更前目录”。
- 缺少权限的菜单项默认隐藏，不能只靠禁用态制造可发现但不可执行的入口；403/接口鉴权由服务端与路由守卫兜底。
- 默认概览按数据域的实际响应处理读取受限：单个运营域或仅项目/健康域 403 不隐藏其他有效 200 内容和布局操作；成功空数组仍是已授权内容。卡片依赖由共享 widget 注册表声明，依赖拒绝域时原位说明读取受限，不冒充真实零值、接入失败或服务宕机。仅四个必要运营域全部 403 时使用受限任务入口；PROJECT 范围文案只在真实 grants 支持时使用，并复用 canonical sidebar menu 的真实授权生成业务能力/Workflow 入口。允许域继续自动和可见性刷新；已 403 域仅在显式刷新或会话身份/授权变化后重新检查。401、后端/网络故障、无可用项目或任务分别处理，旧身份或旧域请求的迟到响应不得覆盖当前界面。现有 GLOBAL 总览与精确项目拒绝保持不变；窄屏及键盘须保持新增状态、刷新和任务入口可达。
- 禁用态必须来自真实业务条件，并在相邻文案或 tooltip 中解释原因。
- 密钥、Token 和 Secret 不进入 URL、日志、Toast 或持久化浏览器文案。

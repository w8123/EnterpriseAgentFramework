# 用同事沉淀的 Skill

> 适合：用 Codex、Claude Code 办业务的业务人员。读完你能把同事整理好的办事做法装进自己的 AI 工具。

## Skill 是什么

Skill 就是一份「这件事该怎么办」的说明书，写给 AI 看的。比如「在芋道 ERP 中查询产品库存」这个 Skill 里写着：先按名称查到产品编号，再用编号查各仓库的库存。

装上之后，你只要说「罗技无线鼠标还有多少库存」，AI 就会按同事验证过的步骤办，少走弯路，也少出错。

Skill 一般是管理人员从大家成功办过的记录里整理出来、审核后发布的（见 [把好的做法沉淀成 Skill](../manager/skills.md)）。

## 开始前你需要

- 已经按 [在自己的 AI 工具里办业务](own-ai-tool.md) 接好了 AI 工具。
- 管理人员已经发布了至少一个 Skill。没有的话，下面第 1 步里不会出现 Skill 列表。

## 第 1 步：找到可用的 Skill

两个地方都能找到，内容一样：

- 业务系统右下角助手 → AI 工具图标「在我的 AI 工具中使用」→ 「可用的做法（Skill）」。
- 个人页 →「我能办的事」→ 页面下方「同事整理好的做法（Skill）」。

每个 Skill 会写清楚它是做什么的、属于哪个系统、版本号。

![个人页「我能办的事」下方的 Skill 列表](../images/manual/business-portal-capabilities.webp)

## 第 2 步：下载并安装

1. 点 Skill 右边的 **下载**，得到一个压缩包。
2. 解压，得到一个文件夹。
3. 把文件夹放到对应目录：

| 你用的工具 | 放到哪里 |
| --- | --- |
| Claude Code | 用户目录下的 `.claude/skills/`，例如 `~/.claude/skills/` |
| Codex | 用户目录下的 `.codex/skills/`，例如 `~/.codex/skills/` |

4. 重新打开 AI 工具。

## 第 3 步：直接说要办的事

不需要提 Skill 的名字，像平常一样说：

```text
帮我在芋道 ERP 里查一下罗技无线鼠标的库存
```

AI 工具发现有对应的 Skill，会按里面的步骤办。可以问它「你是按哪个 Skill 办的？」确认。

## 背后发生了什么

- Skill 只是「做法说明」，不带任何权限。AI 照着 Skill 办事时，用的仍然是你的身份和权限，写操作照样要审批。
- 你只能看到和下载你有权限的系统的 Skill。
- Skill 更新后会有新版本号。想用新版本，重新下载覆盖原来的文件夹即可。

## 遇到问题

**看不到任何 Skill。** 管理人员还没有发布，或者发布的 Skill 不属于你能用的系统。

**装了 Skill，AI 好像没按它办。** 确认文件夹放对了位置，并且重新打开过 AI 工具。Claude Code 可以问它「你现在有哪些 Skill？」。

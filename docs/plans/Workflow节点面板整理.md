# Workflow 节点面板整理

> 2026-10-19。依据用户提供的 LLM、知识检索面板截图，以及当前 `StudioPropertyPanel`、`NodeConfigPanel` 和 20 种配置组件。产品对象与 Runtime 边界沿用[平台定位与架构总览](../01-平台定位与架构总览.md)及 [Workflow Studio 整理方案](Workflow%20Studio整理方案.md)。

## 问题与目标

原面板在「配置 / 测试 / 调试记录」下面重复放置「输入 / 配置 / 输出 / 高级」。名称、描述、输出别名占用首屏，每个字段又被独立包成大卡片；主要配置被挤到下方。LLM 消息编辑、变量引用和预览分散，页面动作参数使用适合宽页面的表格。

目标是让实施人员选中节点后，立即看到当前任务的主要配置；按实际操作顺序完成配置，并随时切换节点测试与调试记录。

## 共用结构

- 顶部直接编辑节点名称，保留模型图标、节点类型、节点标识、删除和收起操作。标题与主标签固定，内容区单独滚动；切换节点或标签回到内容顶部。
- 保留一层「配置 / 测试 / 调试记录」。节点说明默认折叠，专属配置直接展示，输入变量、输出变量和变量契约 JSON 放在底部折叠区域。
- 复用 `ConfigSection` 分区及 `studio-panels.scss`，通过分隔线、字号和间距表达层级。普通字段不再独立套带阴影的卡片；字段列表仍保留边界，便于区分每一项。
- 默认面板宽度仍为 480px，拖动范围仍为 380–960px。表单按容器宽度调整，复杂字段在窄面板中换行。颜色引用现有主题变量。
- 只读状态传递到节点专属配置；交互节点原生按钮也遵守此状态。输出别名已有专属编辑入口的节点不重复提供另一个编辑框。

## 各节点操作顺序

| 节点 | 主要配置顺序 | 按需展开 |
| --- | --- | --- |
| 大模型 | 模型 → 提示词消息 → 输出格式与结构化字段 | 附加上下文、视觉输入、模型参数 |
| 知识检索 | 知识库与查询 → 证据策略 | 检索参数；已有覆盖值时展开 |
| HTTP 请求 | 请求地址 → 请求体 → 认证与超时 | 查询参数、请求头；已有值时展开 |
| 参数提取 | 提取方式 → 目标字段与取值来源 | 自定义提示词；已有内容或提示词错误时展开 |
| 意图分类 | 分类方式 → 分类分支 → 默认分支 | 自定义模型提示词 |
| 条件分支 | 条件组 → 条件表达式 → 默认分支 | 共用变量契约 |
| 循环 | 集合 → 循环体节点 → 入口和出口 | 当前项、索引、结果、次数上限 |
| 能力调用 | 选择业务方法或 API → 来源摘要 → 参数与返回 | 映射备注 |
| 页面动作 | 项目 → 页面 → 动作 → 展示与确认 → 参数来源 | 参数 JSON |
| 交互 | 绑定来源 → 交互表现 → 字段配置 | 原有高级交互配置 |
| 用户输入 | 输出别名 → 输入字段与必填规则 | 共用变量契约 |
| 回复 | 回复模板 | 共用变量契约 |
| 模板转换 | 模板 → 可插入变量 | 共用变量契约 |
| 变量赋值 | 目标 → 取值类型 → 来源或固定值 | 共用变量契约 |
| 变量聚合 | 聚合方式 → 聚合项 | 共用变量契约 |
| 代码 / 表达式 | 转换说明 → 输出表达式 | 共用变量契约 |
| 人工确认 | 确认内容与审批人 → 等待与默认分支 | 共用变量契约 |
| 知识写入 | 知识库与内容来源 → 标签与写入模式 | 共用变量契约 |
| 文档抽取 | 文档来源 → 格式 → 抽取字段 | 共用变量契约 |
| MCP | 服务 → 工具 → 入参映射 | 共用变量契约 |

开始、结束节点保留名称、说明和契约，并解释流程入口、出口的作用。面板整理不扩大运行时允许新增的节点类型。

## 编辑行为

- LLM 的变量搜索与插入、预览放在提示词编辑区；插入到当前选中消息的光标位置，也支持简洁模式的系统、用户提示词。附加上下文仍保留原有运行语义。
- 多条同角色消息、助手消息或停用消息存在时，禁用简洁模式，防止编辑后覆盖原消息。排序、角色和启停变化同步更新提示词快捷字段。
- 页面动作使用纵向参数行替换宽表格，目录加载、参数映射和 JSON 编辑沿用原有逻辑。
- 循环面板检查中发现原有深度监听会无条件重写等价的成员数组，引发递归更新；改为成员内容变化时才写入，保留成员过滤、入口与出口同步行为。

## 验证与边界

- 本地验证：前端生产构建通过（包括类型检查及嵌入 SDK）；Workflow / Agent 共 50 个测试文件、303 项断言通过，测试进程正常结束且无未处理异常。新增检查覆盖 LLM 编辑、循环成员同步、只读配置和切换节点滚动。节点说明使用可手动调整高度的两行文本框，避免折叠、切换节点时的异步高度测量访问已卸载元素。
- 浏览器宽度检查：15 种当前可配置节点及开始、结束节点，在 380px 下均未发生内容横向溢出；测试与调试记录标签可达，另检查了 960px 和暗色变量配色。独立预览的另外 5 种配置组件在窄容器下也无横向溢出。
- 浏览器验证使用实际本地 Workflow 页面：现有 LLM、知识检索、回复、开始、结束节点；通过节点选择器临时添加其他当前可新增节点，检查布局与标签。验证过程不保存或发布这些临时节点。
- 代码 / 表达式、人工确认、知识写入、文档抽取、MCP 使用真实组件与默认样例独立预览，仅验证配置布局，不代表当前运行时开放新增或已完成业务执行。
- 本次修改集中于管理端配置体验，不改数据库、GraphSpec 字段或节点执行协议。发布校验、AI Proposal、Agent Workflow 引用和调试链路通过既有回归检查；未以新增发布或模型付费调用进行线上验收。

3. Control／Runtime 模块职责及持久化访问边界收口；声明模块的循环组、循环边和持久化例外均为零。
4. 按职责拆分 Supervisor、Studio 工作副本、AI Coding、Registry 和 Knowledge 的复杂实现，并补齐对应契约和回归。
5. 修复续跑检查点覆盖、计数归零、调用额度重置、RunOps 误报，以及多选执行／发布契约不一致。

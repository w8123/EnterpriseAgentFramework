# 概览快捷入口设计说明

2026-10-19 用户确认采用紧凑横条方向。快捷入口服务于管理端用户进入常用功能，与概览运营数据共用已有看板组件系统。

## 交互与呈现

- 默认标题为“快捷入口”，使用统一导航图标、短名称、轻量背景与悬停反馈；用途说明放在入口悬停提示中。
- 一个账号首次进入只初始化一个快捷入口组件，优先匹配其角色与实际可访问功能。多角色不再同时铺开三组入口。
- 组件目录提供开发、运营、平台管理和自定义预设。预设共用一个组件实现，可添加多个实例，各自调整标题、入口与顺序。
- 常态“自定义”可直接保存入口；编辑布局时修改先进入草稿，支持撤销、重做、取消和统一保存。组件沿用现有移动、缩放与移除机制。
- 宽度减小时入口换行，窄屏沿用看板的流式布局。概览复用共享侧栏折叠策略，返回桌面宽度时恢复桌面偏好。浅色与暗色使用现有主题变量。

## 权限与个人配置

- 只保存已注册入口 ID，不保存任意 URL、组件名或权限。实际地址、图标与可见性复用共享导航；预设不授予权限。
- 暂时失权的已选入口不会出现在看板中；配置保留，恢复权限后可再次显示。用户主动删除或清空的入口不会自动补回。
- 当前延续浏览器本地持久化，按稳定平台账号 ID 隔离。切换账号会重载布局并丢弃上一账号尚未保存的草稿。
- 当前不支持跨浏览器或跨设备同步。旧未分账号的布局记录保留，不自动归给任一账号，也不覆盖用户已经保存的个性化配置。
- 本次不新增数据库表或服务端布局 API；后续接入服务端时沿用布局仓储接口。

## 验证范围

验证导航授权投影、预设选择、增删排序、空选择、账号隔离、保存恢复、撤销与取消，并运行看板回归和前端构建。浏览器检查常态、设置、组件目录、缩窄和主题适配；登录服务不可用时独立组件预览不等同于已认证管理端验收。

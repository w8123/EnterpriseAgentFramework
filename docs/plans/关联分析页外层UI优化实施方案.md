# 关联分析页外层 UI 优化实施方案

日期：2026-10-12。用户在截图评审后授权“优化一下，要有设计感”。关联实施基线 U2/U3 的契约理解及 U4 的关系参考，不改变已确认产品边界。

## 目标与设计

- 沿用 Glass Workbench，将返回入口、关联分析标题和分析动作合为一个紧凑工作头；下方是分组显示控件和完整画布。
- 单一连续玻璃表面，薄分隔线区分操作层级。文字与间距建立秩序，使用现有主题、圆角、密度和表面 tokens。
- 常驻“契约关联，非实际调用依赖”；详细操作说明放入共享帮助抽屉。连线模式的源节点提示仍常驻。
- 当前能力上下文和“当前能力关联”保留；所有分析、刷新、显示及编辑事件接回原处理函数。
- 仅调整图谱外层 UI；节点、边、图例、布局计算、持久化、接口、权限和业务数据保持。

## 组件与所有权

| 职责 | 现有或新增 owner | 本批处理 |
| --- | --- | --- |
| 页面、主导航和范围 | BusinessCapabilityWorkbench / PageHeader / MainLayout | 保持共享骨架 |
| 工具返回及项目上下文 | SourceWorkbenchPanel / businessCapabilityRoutes | 返回入口移入图谱头，保持 query 清理契约 |
| 图谱工作面 | SourceGraphPanel / glass-surface-panel | 去除旧实色卡片和重复说明 |
| 图谱外层操作 | CapabilityGraphToolbar（新增） | 集中展示，显式 props/emits；与 Canvas 分离 |
| 帮助 Overlay | AppDrawer | 复用可访问抽屉和关闭回焦机制 |
| 按钮、下拉与开关 | Element Plus | 保留 loading、disabled 和 canWrite 条件 |
| 图谱运行行为 | CapabilityGraphCanvas / 原 composables | 仅替换外层模板和 import，保持内部逻辑 |
| 主题和滚动条 | styles/tokens / styles/index.scss | 复用运行时 owner，不新增全局主题值 |

## 实施步骤

1. 保存当前受影响文件的 WIP 副本与工作树清单，核对源文件和 sibling 来源/说明工作面。
2. 为工具栏的事件、权限、帮助和连线提示编写行为测试并确认失败。
3. 实现工具栏，替换三层重复外壳；窄屏工具栏自然换行，画布维持自身滚动与原布局。
4. 更新既有设计/交互契约和实施进度，仅追加本批事实。
5. 跑工作台与图谱目标测试、前端生产构建、相关 UI 守卫、Premium strict audit 与增量差异检查。
6. 通过浏览器查看桌面、窄屏、帮助与分析菜单，核对数据读取、返回和显示选项；不执行分析、清空、连线或位置保存。

## 验证边界

浏览器验证只操作 UI 本地状态及读取。不得用真实图谱写入制造验收；浏览器不可达时如实记录工具障碍，组件测试与构建不代替视觉验收。不提交、推送或部署。

# 全站磨砂弹层覆盖清单

核对日期：2026-10-24。用户明确范围为全站所有尚未改造的弹窗，同时补齐侧边抽屉。

## 盘点口径

扫描管理端与 SDK 的 Vue 模板、相关 SCSS，以及非测试代码中的原生确认框调用。共发现 **123 个弹层相关模板声明，分布在 80 个文件**：AppDialog 84、AppDrawer 29、GlassDialog 3、原生适配器 2、自定义 section / aside 4、模型选择 tooltip 1。另有 **69 个 ElMessageBox 静态调用点，分布在 34 个文件**。

声明数包含公共封装与调用方，不能直接等同于产品中互不重复的弹窗数量。清单表示材质覆盖与源码检查；真实业务保存、发布、调用和认证不以样式检查替代。

## 统一材质与本轮补齐

- 普通业务弹窗、抽屉及确认 / 输入提示框共用 `src/styles/_overlays.scss` 的 `--surface-glass-modal`。亮暗模式均使用磨砂着色与 40px 模糊，提供减少透明度和强制颜色回退。确认框保留原有 420px 最大宽度，窄屏额外限制为视口减 32px。
- 看板组件目录、组件设置 / 快捷入口设置使用公共材质和 LiquidGlassLayer；目录和快捷入口条目也移除大块实底。原有草稿、保存、取消、排序、权限、布局编辑行为保留。
- 清理模型接入向导、来源导入 / 扫描设置、组合配置弹窗、Agent 协作 / 知识库 / Workflow 选择器、API 市场详情 / 接入、来源评审、页面任务详情的局部实底覆盖。代码、表单输入和密集阅读区继续保持必要对比。
- Workflow 模型选择、检查 / 变量面板和高级调试浮层使用 `app-frosted-overlay`。Popover 选择器明确高于通用菜单皮肤，避免材质和回退再次被覆盖。Studio 非模态调试抽屉保持原挂载与工作区行为。
- SDK 记忆面板只依赖 `--reachai-chat-*` 主题，磨砂渐进启用，保留宿主隔离与回退。表单内的业务调用警示确认区保持现有语义状态底，不另做浮动模态。

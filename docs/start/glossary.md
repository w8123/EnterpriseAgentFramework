# 名词表

> 手册里反复出现的词，这里各用一两句话说清楚。按使用频率排序。

## 人和身份

| 名词 | 意思 |
| --- | --- |
| 业务人员 / 员工 | 在 ERP、CRM 等业务系统里干活的人。用业务系统自己的账号，不需要 ReachAI 账号。 |
| 开发人员 | 负责把业务系统接入 ReachAI，搭建助手和流程。管理台里的一种身份。 |
| 管理人员 | 负责审批 AI 的写操作、查看使用情况、管理员工的调用权限。管理台里的一种身份。 |
| 平台管理员 | 负责安装 ReachAI、管理账号、模型和服务器，能看到全部功能。 |
| 「我的」 | 每个管理台账号都有的个人空间：我的首页、AI 工具接入、AI 操作审核、我的记忆。 |
| 工作台 | 管理台按身份分成的菜单。一个账号有多个身份时，左下角可以切换。切换只改变菜单，不改变权限。 |
| 业务用户 | ReachAI 记录的业务系统员工。员工第一次通过 AI 使用某个系统时自动出现，管理人员在「业务用户」里查看和管理。 |

## 业务系统和能力

| 名词 | 意思 |
| --- | --- |
| 项目 | 接入 ReachAI 的一个业务系统，比如「芋道 ERP」。在「项目管理」里看到。 |
| 业务能力 | 业务系统允许 AI 使用的一个功能，比如「查询库存」「新建客户」。分两种：业务方法和 HTTP API。 |
| 业务方法 | 开发人员在代码里加注解声明出来的能力。接入组件会自动同步到 ReachAI。 |
| HTTP API | 业务系统已有的接口，通过手工填写、粘贴 curl 或导入 OpenAPI 文档加进来。 |
| 只读 / 写操作 | 只读是查询，不会改数据；写操作会新建、修改或删除数据，默认需要审批。 |
| 接入组件（SDK / Starter） | 装进业务系统的小组件，负责登记、同步能力、验证 ReachAI 的调用。 |
| 身份桥 | 接入组件的一部分：把 ReachAI 传来的员工身份，还原成业务系统里的登录用户。 |

## AI 相关

| 名词 | 意思 |
| --- | --- |
| Agent（智能体、助手） | 能听懂人话、选择能力去办事的 AI 助手，比如「ERP 助手」。要选一个模型，再告诉它能用哪些流程。 |
| Workflow（流程） | 把几个步骤固定下来的业务流程，比如「按产品名称查库存」。在 Workflow Studio 里拖拽编排。 |
| Skill | 一份写好的「办事做法」，告诉 AI 某件事该按什么顺序、用哪些能力完成。可以从成功的运行记录里一键生成，员工下载后放进自己的 AI 工具。 |
| 模型 | 提供智能的大模型服务，比如 DeepSeek、通义千问。在「模型中心」接入。 |
| 知识库 | 上传的企业资料（制度、手册等），助手回答时可以引用。 |
| 记忆 | 助手记住的个人偏好，比如「我负责华东区」。分个人记忆和项目记忆，只有本人能看到自己的个人记忆。 |

## 连接与开放

| 名词 | 意思 |
| --- | --- |
| 嵌入对话 | 放进业务系统页面里的 AI 助手窗口。 |
| 页面动作 | 业务页面允许 AI 帮忙做的操作，比如筛选列表、打开详情、填写表单。 |
| 个人连接（员工连接） | 员工给自己的 AI 工具生成的连接，让 Codex 等工具以本人身份办业务。只显示一次，不能转给别人。 |
| 平台 AI 连接 | 管理台账号给自己的 AI 工具生成的连接，让 Codex 帮你操作 ReachAI 本身，比如建流程、看记录。 |
| 「交给我的 AI」 | 管理台很多页面上的按钮。点一下得到一段提示词，粘贴给你的 Codex，它就能接着把这件事做完。 |
| MCP | AI 工具连接外部系统的通用协议。员工不需要懂，开发人员知道 ReachAI 通过它对 AI 工具开放能力即可。 |
| MCP 服务 | 管理台「MCP 开放」里的一组能力，开通「员工使用」后，员工的 AI 工具才能看到这些能力。 |

## 运行和治理

| 名词 | 意思 |
| --- | --- |
| 审批单 | AI 要做写操作时生成的单子，冻结了谁、做什么、参数是什么。管理人员批准后才执行。 |
| 运行记录 | 每次 AI 办事的完整记录：用了哪些能力、每一步的输入输出、耗时、结果。在「运行中心」查看。 |
| 调用权限 | 规定哪些角色可以使用哪些能力。在「身份与权限 → 调用权限」里配置。 |
| 自动化 | 定时让助手办一件事，比如每天 9 点发库存预警。在「自动化中心」配置。 |

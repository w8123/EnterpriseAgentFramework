# 用 Claude Code 操作芋道

员工在芋道 ERP 的 AI 对话面板里勾选系统、复制一行内容，就能在自己的 Claude Code、Codex 等 AI 工具里，以**本人的芋道账号**查库存、建客户。员工不需要知道 MCP，也不需要去芋道做任何授权。

方案背景见 [员工身份MCP接入方案](../plans/员工身份MCP接入方案.md)。

## 一、管理员：开通一次

前提：芋道已按 [芋道ERP接入ReachAI实施步骤](./芋道ERP接入ReachAI实施步骤.md) 接入，对话面板能正常使用。

1. 进入 **MCP 互联中心 → 对外发布**，新建（或打开）一个发布，把员工要用的芋道能力加为条目，预检后发布。
   - 不可逆（IRREVERSIBLE）的工具不会开放给员工，即使发布里有。
2. 打开发布详情的 **员工使用** 页签：
   - 打开「员工可用」；
   - 业务系统选芋道（例如 `yudao-erp`）；
   - 员工看到的名称填「芋道 ERP」；
   - 保存。
3. 员工能用哪些工具，仍按 **调用权限** 里的业务系统角色控制（与对话面板一致）。员工的角色在他每次打开对话面板时从芋道同步。

## 二、员工：接入自己的 AI 工具

1. 在芋道里打开 AI 对话面板，点 **在我的 AI 工具中使用**。
2. 勾选要接入的系统（默认已勾选芋道），选择自己用的 AI 工具，点 **生成连接**。
3. 按面板提示复制那一段内容：

   | AI 工具 | 怎么用 |
   | --- | --- |
   | Claude Code | 在终端运行 `claude mcp add --transport http reachai https://<ReachAI 地址>/mcp/employee --header "Authorization: Bearer rai_…"`，然后重新打开 Claude Code |
   | Codex | 把 `[mcp_servers.reachai]` 这一段粘贴到 `~/.codex/config.toml` 末尾，然后重新打开 Codex |
   | 其他 AI 工具 | 把 `mcpServers` 这段 JSON 粘贴到工具的 MCP 配置里 |

4. 直接说要做的事，例如「查一下罗技鼠标的库存」「帮我新建客户：上海某某贸易有限公司」。

注意：

- 这段内容**只显示一次**，里面有你的个人连接密钥，不要发给别人。丢了就断开旧连接、重新生成。
- 连接 90 天后过期；每人最多同时保留 10 条使用中的连接。
- 员工离职或换岗时，管理员在「员工连接」里断开他的连接即可立即失效；员工在 ReachAI 里被停用后，连接也不再能用。

## 三、管理员：查看和断开

- **MCP 互联中心 → 员工连接**：按员工姓名、业务系统账号、业务系统、状态筛选；可以直接断开任何一条连接。
- 点某条连接的 **调用记录**，跳到 **调用流水** 并只看这条连接的调用。流水的「调用方」一列显示员工姓名和 AI 工具。
- 每次调用同时出现在 **运行中心**，执行身份是员工本人，芋道里的操作人也是这名员工。

## 四、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 面板里提示「暂时没有可以接入的系统」 | 管理员还没在发布详情的「员工使用」里开通，或该发布还没发布修订 |
| AI 工具报 401 | 连接已断开、已过期或密钥复制不完整；重新生成 |
| 某个工具调用被拒绝 | 员工的芋道角色在「调用权限」里没有这个工具的允许规则 |
| 看不到删除类工具 | 有意为之：不可逆工具不对员工开放 |

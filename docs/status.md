# 当前边界

本页只说明当前实现边界和需要继续验证的条件。功能入口以源码、配置和 manifest 为准；本页不保存批次、提交、历史测试结果或执行授权。

## 可用实现与开放条件

| 范围 | 当前边界 |
| --- | --- |
| Java 方法与 HTTP API | 独立 owner、来源接纳、Console、固定 Workflow 引用和受控试运行；验收须覆盖下表 U1–U4 |
| Agent / Workflow | 发布配置、白名单、GraphSpec、草稿调试与运行；节点按真实 Handler 与发布校验开放 |
| 流式对话 | Agent / Embed transport 声明 token streaming；Workflow working-copy transport 的 `tokenStreaming=false`；真实代理 flush、逐块到达与取消需按部署验证 |
| 运营看板 | 已有采样统计、Widget 和账号隔离的浏览器本地布局；统一统计 BFF、服务端布局、跨设备同步及独立 Screen / 项目运营路由不作为已交付能力 |
| Skill 经验沉淀 | 已有运行捕获、预览与进入审核流的源码；真实来源权限、脱敏、审核、员工下载及 Workflow 草稿应走完整验收 |
| 自动化 / 评测 / 托管执行 | 有独立配置开关；实际开启、外部依赖、安全、容量与恢复按运维准入判断 |

## 业务能力验收

| 用户任务 | 成功条件 |
| --- | --- |
| U1 开发者接入与维护 | 声明只读/写方法、可信同步、正确契约与状态、真实试调用、变化影响可查；不人工复制通用 Tool |
| U2 实施人员使用方法 | 能找到并理解方法、确认操作影响、处理失败、在 Studio 映射输入输出、发布运行，并回查同一 owner 的 Trace 与使用位置 |
| U3 接入与使用 API | Controller / OpenAPI 来源、同源去重与冲突、跨项目隔离、必要连接、GET / POST、UNKNOWN 查询及 Workflow 执行一致；市场收录不代替验证 |
| U4 处理变化 | 展示变化与执行变化分开；草稿、发布和开放引用可定位；旧 pin 不静默迁移，接纳后显式重发布 |

整体验收还需验证旧重复维护入口不再产生资产、受影响消费者正常、真实角色可完成任务、窄屏/键盘/原生缩放可操作，并核对 SQL、表归属、服务签名、源代码与真实环境一致。引用或验证未知时明确说明，不能显示为零或已通过。

## 产品范围

当前主线是业务系统接入、员工 AI 工具、写审批、运行经验复用和使用治理。MCP 入向注册/同步与编排消费、A2A 新增扩展、Managed Executor 新方向及无具体任务的全站 UI 扩张不自动启动。

A2A 的异步授权/输入恢复、subscribe/push、生产认证与稳定快照/TCK，业务索引的 Agent 自动检索，以及托管执行的目标集群/攻击验收，不能因有类型、页面或局部测试而视为已开放。

后续工作从具体用户任务进入，按[运维验收](operations.md)验证。新增产品边界先明确用户价值与影响，不能通过删改文档把目标、未验条件或权限限制写成已完成。
